# WeatherApp-Android
Aplicativo Android simples para buscar a previsão do tempo com base na cidade digitada pelo usuário.

## Funcionalidades
- Entrada de nome da cidade
- Botão para buscar a previsão
- Resultado exibido na tela
- Interface básica e funcional

## Tecnologias usadas
- Kotlin
- Android Studio
- Volley (requisições HTTP)
- Material Design

## Como rodar
1. Clone o repositório:
```bash
git clone https://github.com/SEU_USUARIO/weatherapp.git
```
2. Abra no Android Studio
3. Rode no emulador ou dispositivo com depuração USB ativa
